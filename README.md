# Soma de Dois Números — Java

## 📌 Sobre o projeto

Este projeto foi desenvolvido durante meus estudos de programação, utilizando Java e a IDE Eclipse. O objetivo é criar um programa capaz de receber dois números, calcular a soma entre eles e exibir o resultado.

## 🎯 Objetivo

Praticar os conceitos básicos de lógica de programação e desenvolver familiaridade com a linguagem Java e o ambiente de desenvolvimento Eclipse.

## 🛠️ Tecnologias utilizadas

- **Java** — linguagem de programação.
- **Eclipse IDE** — ambiente utilizado para desenvolver e executar o programa.

## ▶️ Como executar

1. Instale o Java JDK e o Eclipse IDE.
2. Importe ou abra o projeto no Eclipse.
3. Localize a classe principal do programa.
4. Execute o método `main`.
5. Informe os números solicitados, caso o programa utilize entrada de dados, e confira o resultado da soma no console.

## 📚 Aprendizados

- Fundamentos da linguagem Java.
- Operações aritméticas.
- Lógica de programação.
- Desenvolvimento e execução de programas no Eclipse.

## 🎓 Contexto acadêmico

Projeto introdutório desenvolvido durante minha formação acadêmica em Computação.
